# 몬스터 / 해상 위협 시스템 작업 명세

> 이 문서는 **확정된 육상 몬스터 40종(일반 32종, 희귀 8종)**과 **확정된 해상 위협 3종**의 작업 기준을 정리한다. 구체적인 출현 확률 및 전투 세부 수치 등은 별도 결정 전까지 미정으로 둔다.

## 2026-10-25 적용 우선 규칙

- 사용자 요청으로 지금은 육상 몬스터·크라켄의 처치 아이템 드랍을 비활성화한다. 해적선 상자 약탈·낚시는 별도 상호작용으로 유지한다.
- 육상 출현 확률은 적용하지 않고 섬 크기·보행 면적에 맞춰 일반 4종을 고르게 배치한다. 문서의 희귀 몬스터를 현재 에픽으로 표시하고 섬마다 해당 에픽 1마리를 배치한다.
- 사용자 승인으로 확인용 초기 골드 50을 지급한다. 이번 임시 배치/전투/성능 정책과 확인 절차는 [MONSTER_IMPLEMENTATION_REPORT.md](MONSTER_IMPLEMENTATION_REPORT.md)에 기록한다.
- 아래 해상 위협의 과거 미정 항목은 현재 [player.md](player.md)와 [PIRATE_BOARDING_REPORT.md](PIRATE_BOARDING_REPORT.md)의 사용자 확정 규칙으로 보완한다. 손실은 종류 전체가 아닌 개별 수량 차감이며 토네이도는 5초 내 A/D 교대 12회다.

## 1. 기본 출현 환경 (확정)

- 각 섬의 소규모 항구 마을 면적은 섬 전체의 **최대 20%**다.
- **몬스터는 마을 외부 지역에 등장**한다. 마을 내부는 몬스터 등장 구역에서 제외한다.
- 섬의 크기는 **40~80m**, 섬 사이 최소 거리는 **300m 이상**이다.
- 섬 형태는 원형(37%) 및 초승달형/U자형/아령형/불규칙형/물방울형/분열형/암초군형(각 9%)의 8종이다.

## 2. 해상 위협 3종 (확정)

### A. 해적

- 플레이어의 배에 실린 아이템을 노리고 공격한다.
- 플레이어를 기준으로 반경 **150m**에 해적선 **약 2척**을 소환해 둔다.
- 플레이어가 해적선 기준 반경 **50m** 이내에 들어오면 추격을 시작한다.
- 해적과의 전투에서 패배하거나 약탈 복귀에 실패하면 선박 아이템 창에서 **무작위 물건 3개**가 소실된다.

### B. 크라켄

- **30초마다 1%** 확률로 등장 판정.
- 바다에서 **촉수 4개**가 솟아올라 선박을 공격한다.
- 배가 파괴되기 전에 촉수를 공격하여 **잘라내야** 한다.
- 성공 시 촉수 보상이 예정되어 있으나 현재는 사용자 요청으로 **아이템 드랍 비활성화** 상태다.
- 실패 시 선박 아이템 창에서 **무작위 물건 2개**가 소실된다.

### C. 토네이도

- **20초마다 1%** 확률로 생성 판정.
- 발생 시 하늘이 어두워지고 **비·천둥·번개**가 시작된다.
- 배 크기 정도의 토네이도가 **2~3개** 생성된다.
- 토네이도에 휘말리면 **A/D 키 연타**로 탈출할 기회가 주어진다.
- 탈출에 실패하면 선박 아이템 창에서 **무작위 물건 4개**가 소실된다.

### 미정 사항

- 해적 2척 배치의 재생성/중복 방지 주기, 크라켄·토네이도 중복/동시 발생 처리, 지속 시간·전투 상세 AI.
- 전투 승패·촉수 절단 판정, 토네이도 A/D 연타의 성공 기준 및 제한 시간.
- 아이템 **종류별 소실**의 수량 처리, 보유 종류가 부족한 경우의 규칙.

## 3. 육상 몬스터 (**확정: 일반 32종 + 희귀 8종**)

> 아래 표의 8개 섬 유형별 일반 몬스터 4종과 희귀 몬스터 1종을 **정식 등장 몬스터로 확정**한다. 단, 개별 몬스터의 출현 확률, 능력치와 희귀 몬스터의 정확한 등장 조건은 미정이다.

| 섬 | 일반 몬스터 4종 (확정) | 희귀 몬스터 1종 (확정) |
|---|---|---|
| 원형 | 멧돼지, 숲 늑대, 나무 정령, 거대 벌 | 고대 나무 정령 |
| 초승달형 | 거대 소라게, 해안 게, 해파리 정령, 세이렌 | 진주 수호자 |
| U자형 | 나무 골렘, 밧줄 괴물, 도둑 고블린, 갑판 쥐 | 난파선의 망령 |
| 아령형 | 거대 카멜레온, 독거미, 덩굴 괴물, 야생 원숭이 | 환영의 카멜레온 |
| 불규칙형 | 돌 골렘, 수정 박쥐, 광석 벌레, 동굴 트롤 | 수정 골렘 |
| 물방울형 | 맨드레이크, 꽃 정령, 거대 나비, 독버섯 괴물 | 꽃의 수호 정령 |
| 분열형 | 늪 도마뱀, 물 슬라임, 거대 개구리, 수초 괴물 | 심연의 수로 수호자 |
| 암초군형 | 가시 성게 괴물, 암초 게, 바다뱀, 해안 하피 | 암초의 포식자 |

## 4. FPS / 렌더링 성능 준수사항 (모든 작업 공통)

1. 동일한 몬스터 모델이 반복 등장하면 **GPU 인스턴싱**으로 렌더하고 메시/머티리얼을 공유해 Draw Call과 중복 메모리를 최소화한다. 서로 다른 애니메이션 상태에는 필요한 개별 상태 데이터를 유지한다.
2. **먼 청크는 렌더링 제외**한다. 플레이어 주변 청크의 가시 몬스터와 활성 해상 위협만 렌더 대상으로 삼는다.
3. 화면 밖 또는 비활성 청크의 몬스터/해상 AI를 불필요하게 매 프레임 정밀 처리하지 않는다. 렌더링 여부와 게임상 지속 상태/시뮬레이션을 구분한다.
4. 위협 등장 시 모델·이펙트·파티클이 프레임을 과도하게 점유하지 않도록 Draw Call, 활성 개체 수 및 리소스 수명을 관리한다.
5. **목표 FPS, 청크 크기, 렌더 거리, 활성 AI 반경, 출현 개체 상한**은 아직 정해지지 않았다. 임의 확정하지 않는다.

## 5. 기술 기반 및 구현 원칙

- 최초 기획서의 기술 기반은 **C++ + OpenGL**이다. 이 명세만으로 DirectX 12 등으로 변경됐다고 판단하지 않는다.
- 해상 위협 3종의 확정 규칙과 **육상 몬스터 40종의 등장 목록**을 유지한다. 미정인 출현 확률·세부 능력치·행동 수치는 임의로 확정하지 않는다.
