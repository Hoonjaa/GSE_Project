# NPC / 퀘스트 / 동료 / 관계 시스템 작업 명세

> 이 파일은 각 섬의 NPC, 동료 영입, 상거래 호감도, AI 대화에 관한 현재 확정 사항과 기존 초안의 방향을 정리한다.

## 1. 각 섬의 퀘스트 NPC 및 동료 영입 (확정)

- **섬마다 약 3명의 NPC**가 플레이어에게 퀘스트를 제공한다.
- 플레이어가 **해당 NPC의 퀘스트를 완료**하면 그 NPC를 **동료로 영입할지 선택**할 수 있다.
- 동료 상한은 선박의 탑승 가능 인원에 의해 결정된다.
- 초기 소형 선박은 **최대 동료 2명**, 선박 업그레이드 후 **최대 5명**까지 가능하다.
- 중간 선박별 동료 상한, 퀘스트 유형 및 NPC 개별 설정은 미정이다.

## 2. 마을과 NPC의 역할 (확정)

- 각 섬의 마을은 **소규모 항구 마을**로 섬 면적의 **최대 20%**를 점유한다.
- 플레이어는 마을에서 아이템을 거래하고, 탐험 아이템/물고기/무역 상품을 판매할 수 있다.
- 각 섬 마을의 **특산품은 섬 형태**에 따라 정해진다. 현지 특산품은 저렴하게 구매할 수 있다.

### 특산품 참조표

| 섬 형태 | 특산품 |
|---|---|
| 원형 | 곡물, 열대과일, 목재, 약초 |
| 초승달형 | 진주, 조개, 소금, 건어물 |
| U자형 | 선박용 밧줄, 돛천, 목공품, 가공 해산물 |
| 아령형 | 향신료, 염료, 직물, 수공예품 |
| 불규칙형 | 철광석, 구리광석, 보석 원석, 석재 |
| 물방울형 | 꽃, 향유, 꿀, 약용식물 |
| 분열형 | 해조류, 게, 새우, 산호 장식품 |
| 암초군형 | 성게, 해면, 희귀 조개, 바닷새 깃털 |

## 3. NPC 호감도와 가격 (확정)

- NPC 호감도가 높으면 **더 싼 가격에 구매하거나 더 비싸게 판매**할 수 있다.
- 플레이어가 **지나치게 비싼 가격에 판매**하면 호감도가 감소할 수 있다.
- 호감도에 따른 가격 배율, 거래 평가 기준, 친밀도 한계치는 아직 정하지 않았다.

## 4. 기존 초안의 NPC 관계 방향 (기존 설계 원칙)

- NPC는 정체성, 가치관, 개인적 목표, 지식, 기억 및 사회적 관계를 가진다.
- 관계는 호감뿐 아니라 **신뢰, 존경, 두려움, 원한, 친밀감, 이해관계** 등 여러 차원으로 다룬다.
- 플레이어의 도움·배신·약속·퀘스트 결과에 따라 NPC의 반응과 관계가 달라진다.
- 관계에 따라 친구·동료·경쟁자·숙적·적이 될 수 있으며, 동료가 된 뒤에도 관계 변화가 가능하다.
- 위 항목들은 기존 초안의 설계 방향이며 **구체적 게임 규칙/수치로 확정된 것은 아니다**.

## 5. 기존 초안의 AI 대화 방향

- **세계의 실제 사실·아이템·퀘스트 보상은 게임 규칙이 관리**하며 대화 AI가 임의로 변경할 수 없다.
- NPC에게 허용된 지식/기억/소문과 감정·관계를 바탕으로 AI가 대사를 생성한다.
- 중요한 대화 결과는 구조화된 기억으로 저장한다. AI 요청은 **매 프레임 수행하지 않고** 대화/사건/상태 변화 시에 처리한다.
- AI 지연 또는 사용 불가 시 기본 대화로 게임 진행 가능하게 한다.
- 기본 언어는 **한국어**다. AI 모델/서비스 및 대화 인터페이스 세부 사항은 미정이다.

## 6. FPS / 렌더링 성능 준수사항 (모든 작업 공통)

1. 반복적으로 등장하는 동일 NPC 메시/장비/배경 모델은 **GPU 인스턴싱** 및 공유 리소스를 활용하여 Draw Call을 최소화한다(개별 외형·애니메이션·머티리얼 제약 고려).
2. **플레이어와 멀어진 청크는 렌더링하지 않으며**, 해당 청크 NPC도 시야 밖에서 불필요하게 렌더하지 않는다.
3. 원거리 또는 비활성 NPC의 AI/일정/관계 시뮬레이션을 매 프레임 전수 실행하지 않는다. 필요 시 사건 중심/요약 갱신을 적용한다.
4. AI 대화/기억 처리는 렌더링 메인 루프를 블로킹하지 않도록 설계하며, 반복 모델 데이터 복제를 피한다.
5. 목표 FPS, NPC 활성 거리, 청크 크기, 업데이트 빈도 및 AI 호출 예산은 **미정**이다.

## 7. 미정 / 별도 결정 필요

- 3명의 NPC 세부 인물상·퀘스트 목록·보상 및 섬별 변형.
- 퀘스트 완료 이외의 영입 추가 조건(있다면), 동료 이탈/재영입 상세 규칙.
- NPC별 가격 공식·호감도 변동량 및 AI 대화 모델 선택.
- 최초 기획서는 C++ + OpenGL 기반이다. API 변경은 별도 확인 사항이다.

**작업 원칙:** 확정된 퀘스트→선택적 동료 영입과 정원 규칙을 유지한다. 미정값은 임의로 확정하지 않는다.
