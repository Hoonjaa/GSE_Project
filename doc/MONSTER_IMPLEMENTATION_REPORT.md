# monster.md 적용 보고서

작성일: 2026-10-25

## 현재 적용 범위

8가지 형태를 빠르게 확인하려면 [ISLAND_TEST_MAP_README.md](ISLAND_TEST_MAP_README.md)의 T 왕복 테스트 맵을 사용한다. 테스트 맵은 2행×4열에 모든 형태를 고정 배치하며 F1~F8로 이동한다.

- 문서의 육상 몬스터 40종을 모두 등록했다. 섬 유형마다 일반 4종과 에픽 1종으로 구성되며, 문서의 희귀 8종을 현재 UI에서 에픽으로 표시한다.
- 시작섬의 기존 산호 게·산호갑각 대장 배치를 교체하고, 스트리밍되는 모든 섬에 새 몬스터 배치를 적용한다.
- 플레이어 클릭 근접 공격·체력·경험치·레벨은 기존 진행 시스템을 사용한다. 몬스터 모델·배치·추격·귀환·재등장 상태는 별도 MonsterSystem/MonsterActor로 분리했다.
- 육상 몬스터와 크라켄의 처치 아이템 보상은 비활성화했다. 무기·강화석·산호·촉수 직접 지급이나 필드 드랍을 만들지 않는다. 육상 몬스터 경험치는 일반 18 / 에픽 160의 기존 프로토타입 값을 사용한다.
- 해적선 상자 약탈과 낚시는 몬스터 처치 드랍과 별개여서 기존 규칙을 유지한다.
- 사용자 승인에 따라 새 실행의 초기 골드가 50이다. 조선소에서 8m 돛단배를 구매해 다른 섬을 확인할 수 있다. R 복귀는 골드를 재지급하지 않는다. EconomyRules::InitialGold를 변경하면 테스트 지원금을 제거할 수 있다.

## 배치 규칙: 확률 대신 확인용 분포

- 섬에 대응하는 일반 4종을 순환 배치하므로 종류별 개체 수 차이는 최대 1마리다.
- 임시 목표 수량은 마을 밖 보행 가능 면적 100㎡당 1마리, 최소 8마리다. 에픽은 일반 수량과 별개로 섬당 1마리만 생성한다. 이는 최종 출현 확률이나 개체 상한을 확정한 것이 아니다.
- 후보는 마을 밖 육지이며, 우선 마을 경계에서 약 2m, 시작 지점에서 5m를 띄우고 0.5m 주변 여유를 확인한다. 좁은 형태에서는 마을 밖의 보행 가능 후보로 완화한다. 마을 안·물·건물 안에는 생성하지 않는다.
- 에픽은 가능하면 항구에서 이어진 영역의 여유 있는 먼 지점에 먼저 배치한다. 해당 조건의 후보가 없으면 일반 보행 후보로 완화해 한 마리를 확보한다.
- 일반 몬스터는 이미 선택한 위치들에서 가장 멀리 떨어진 후보를 반복 선택한다. 기본 2m 간격을 지키되 최소 4종 확인을 우선한다. 공간이 부족하면 실제 수량이 목표보다 적을 수 있다.
- 분열형/암초군형의 떨어진 육지에도 일반 몬스터가 분포할 수 있다. 바다를 걸어서 건너지 않으며 해당 육지에 배로 상륙해 확인한다.
- 정상 지도 생성에서도 적법한 마을 밖 보행 칸이 하나도 없는 경우는 오류 로그 monster_spawn_no_legal_cells로 식별한다. 불법 위치에 억지로 생성하지 않는다.

## 전투와 임시 조정값

아래는 몬스터 확인을 위해 기존 산호 몬스터 전투에서 가져온 프로토타입 수치다. 종별 최종 능력치·독/매혹 같은 고유 기술·출현 확률은 아직 확정하지 않았다. MonsterPreviewRules에서 현재 값을 모아 관리한다.

| 항목 | 일반 | 에픽 |
|---|---|---|
| 체력 | 36 | 360 |
| 피해 | 8 | 30 |
| 이동 속도 | 1.9 | 1.5 |
| 원래 위치 기준 어그로 반경 | 12m | 13m |
| 공격 예고 시간 | 0.65초 | 0.95초 |
| 예고 공격 범위 | 1.35m | 3.6m |

- 붉은 공격 예고 원, 피격 점멸·피해 숫자, 몬스터 한국어 이름·체력바를 표시한다. 에픽은 보라색 발밑 고리와 [에픽] 이름으로 구분한다.
- 마을에서는 생성과 추격 이동을 막고 플레이어에게 공격하지 않는다. 어그로 해제 시 제자리 순간이동 대신 지형·마을 경계를 피해서 원래 위치로 걸어 돌아가며 체력 회복은 기존 정책을 유지한다.
- 일반 몬스터는 25초 이후 플레이어가 집 근처에 없으면 재등장한다. 에픽은 해당 섬이 메모리에 있는 동안 처치 상태를 유지한다.
- 몬스터 상태의 파일 저장은 이번 범위에 없다. 섬의 모든 청크가 언로드되었다가 다시 로딩되면 배치를 결정론적으로 다시 만들므로 처치한 에픽도 재생성될 수 있다. 전체 게임 재실행 때도 초기 상태부터 시작한다.

## 구조와 성능

- MonsterCatalog: 문서 순서에 맞춘 40개 ID·이름·모델 유형·색·등급과 섬 유형 매핑.
- MonsterMeshes: 단순 입체 도형으로 동물·식물·게·골렘·곤충·날개·촉수 등의 외형을 구분하는 프로토타입 모델. 정식 아트·리깅 자산은 후속 작업이다.
- MonsterActor/MonsterContext: 로컬 섬 좌표, 보행 연결, 공유 추격 거리장, 귀환 경로, 근접 전투·표시.
- MonsterSystem: 섬별 개체 수명과 배치, 월드 청크 활성 범위, 클릭 판정, 경험치 콜백.
- LevelOne은 시작섬에 묶였던 몬스터 배치를 제거하고 플레이어 진행/전투 효과를 제공한다. 다른 섬에서도 같은 체력·경험치·검 공격을 사용한다.

동일 종은 파일 캐시 키 monster_species_v1_ID의 메시를 공유하고 Renderer의 인스턴싱 배치에 모인다. 공격 예고·에픽 고리는 각각 하나의 공용 메시다. 피격 점멸은 인스턴스별 GLSL HitFlash로 처리하므로 점멸용 모델을 복제하지 않는다. 모델은 섬의 해당 종류를 처음 준비할 때만 생성/로드한다.

그룹은 현재 로딩된 월드 청크에 대응하는 섬만 유지한다. 그 섬의 청크가 모두 사라지면 몬스터 Actor와 레이아웃 참조도 해제해 무한 월드에서 몬스터 때문에 섬 레이아웃이 계속 남지 않게 한다. 렌더링은 현재 위치가 활성 청크 안에 있는 살아 있는 몬스터만 제출한다.

현재 확인용 시뮬레이션은 플레이어와 같은 섬의 24m 안을 정밀 갱신하고 나머지 활성 청크 몬스터는 0.25초 누적 갱신한다. 비활성 청크는 갱신을 중단한다. 이 값도 최종 게임 반경·주기 확정이 아니다. 보행 가능한 셀과 연결을 섬 로딩 시 준비하고, 추격 거리장은 목표 셀이 바뀌었을 때 최대 0.25초 간격으로 공유 갱신한다. 귀환 거리장은 직선이 막힌 개체만 생성하여 귀환 중 재사용한다.

## 로그와 확인 방법

- monster_preview: 목록 수·일반/에픽 수·드랍/확률 비활성 여부.
- monster_spawn: 섬 좌표·종 ID·등급·로컬 위치.
- monster_island_ready: 섬 폭·배치 면적·실제 일반 개체 수·에픽 1개·배치/자산 준비 CPU 시간.
- monster_resident_created: 보행 격자·연결 준비까지 포함한 섬 몬스터 생성 전체 CPU 시간.
- monster_hit / monster_defeated / monster_attack: 종 ID·체력·피해·드랍 비활성 및 플레이어 공격 시도.
- monster_island_unloaded: 섬별 개체 해제.
- economy_initial_gold / kraken_defeated: 테스트 자금과 해상 드랍 비활성 확인.

기존 FPS/draw/batches/CPU/static 업로드 로그도 유지한다. 모델 40종 전체를 매 프레임 만들거나 업로드하지 않는다. 섬별 실제 인스턴스 수·드로우콜은 실행 후 확인해야 하며 측정하지 않은 감소 수치는 제시하지 않는다.

빌드·실행·렌더링 결과 확인은 사용자 요청에 따라 수행하지 않았다. 프로젝트 XML·파일 경로·소스/필터 등록·PCH 첫 include, 문서와 일치하는 40종 이름·ID·섬별 4+1 등급, 모델 유형 처리 누락, 드랍 생성 경로, 코드 형식과 참조를 정적으로 점검했다. 실제 개체 수와 에픽 위치는 실행 후 로그·화면에서 확인해야 한다.

수동 확인 순서:

1. 새 실행에서 골드 50을 확인한다. 시작 원형 섬의 멧돼지·숲 늑대·나무 정령·거대 벌과 고대 나무 정령 [에픽]을 확인한다.
2. 상점·조선소 주변과 마을 안에는 몬스터가 없고, 섬 바깥쪽에 개체가 고루 분포하는지 확인한다.
3. 클릭 공격·경험치·레벨업, 붉은 공격 예고·피격·추격·귀환을 확인한다. 처치 후 아이템·골드·강화석이 증가하거나 필드 드랍이 생성되면 안 된다.
4. 배를 구매해 나머지 7가지 형태의 섬을 방문한다. 각 4종의 일반과 문서의 해당 에픽을 이름·외형·로그로 확인한다.
5. 크라켄 승리 시 촉수 지급이 없고, 해적선 상자는 별도 약탈 규칙을 유지하는지 확인한다.
6. 섬을 떠나 청크를 언로드하고 재방문해 Actor/메시 수가 무한 증가하지 않는지, 위치·종류 배치가 재현되는지 확인한다.
