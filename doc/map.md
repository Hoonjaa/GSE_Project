# 맵 + 특산품 시스템 작업 명세

> 목적: 이 파일만 전달해도 맵·섬·특산품·무역의 **확정된 요구사항**과 성능 준수사항을 확인할 수 있도록 작성한다. 명시되지 않은 수치나 기능은 구현 전에 확인한다.

## 1. 확정된 월드 설정

- 장르/배경: 밝은 대항해 시대풍 2.5D 오픈 월드 RPG.
- 맵은 청크(chunk) 단위로 필요 영역을 생성하며, 고정된 경계 없이 확장되는 구조를 지향한다.
- 플레이어의 지름 기준: 약 **0.4m**.
- 섬 크기: **40~80m**, **섬의 최대 폭** 기준. (2026-10-24 사용자 확인)
- 서로 다른 섬 사이의 최소 거리: **300m 이상**, **해안선 사이 거리** 기준. (2026-10-24 사용자 확인)
- 각 섬의 마을은 **소규모 항구 마을**이며, **섬 전체 면적의 최대 20%**만 차지한다.
- 마을 외부 지역에서 몬스터가 등장한다. 마을 내부는 몬스터 출현 구역에서 제외한다.
- **시작섬은 원형 섬**이다. 플레이어는 이곳에서 초기 자금을 모아 돛단배를 구매한 뒤 다른 섬을 탐험한다.

## 3. 무역 및 가격 원칙 (확정)

- 섬의 형태에 따라 **해당 섬 마을의 특산품이 결정**된다.
- 해당 마을의 특산품은 **현지에서 싸게 구매**할 수 있다.
- 특산품이 아닌 품목은 다른 지역에서 **상대적으로 비싸게 판매**할 수 있다.
- 플레이어는 지역 간 특산품 매매로 수익을 얻는다.
- 탐험으로 얻은 고가치 아이템을 마을에 판매할 수 있다.
- 마을 NPC와의 호감도에 따라 더 싼 구매가/더 높은 판매가가 가능하다.
- 지나치게 높은 가격으로 판매하면 NPC 호감도가 내려갈 수 있다.
- 구체적인 기본 가격, 거래 공식, 호감도 증감량은 **미정**이다.
- 초기 맵 작업에서는 가격 미정 거래를 비활성화했다. 이후 2026-10-24 추가 확정으로 **마을마다 상점 1개·조선소 1개**, **일반 산호 전리품 5골드·보스 산호 전리품 20골드 매입**, **8m 돛단배 50골드 구매**를 활성화한다. 나머지 특산품의 가격·호감도 배율은 계속 미정이다.

## 4. 청크 기반 생성 및 저장 방향 (기존 초안)

- 월드 시드와 청크 좌표를 기반으로 동일한 기본 지역을 재생성하는 결정론적 생성.
- 주변 활성 청크 위주로 메모리를 유지하고, 접근 예정 청크는 미리 생성·로딩한다.
- 멀어진 청크의 변경 사항은 별도 저장한 뒤 메모리에서 언로드한다.
- 방문·발견·변경 상태는 재방문 시 복원한다.
- 생성 단계는 큰 해역 → 지역/군도 → 청크/해안선 → 세부 오브젝트를 따르는 방향이다.

## 5. FPS / 렌더링 성능 준수사항 (모든 작업 공통)

1. 반복 등장하는 **동일 메시·머티리얼 모델**(예: 바위, 나무, 섬 구성 오브젝트, 동일 몬스터)은 가능한 범위에서 **GPU 인스턴싱**으로 처리해 Draw Call을 줄인다. 동일 기하 데이터의 불필요한 중복 할당을 피한다.
2. 플레이어 청크와 **가까운 청크만 렌더링**한다. 충분히 멀어진 청크는 렌더 호출 대상에서 제외한다.
3. 청크별 활성화·비활성화·언로드 경계를 분리하고, 보이지 않는 먼 지역의 오브젝트를 매 프레임 렌더/갱신하지 않는다.
4. 청크 생성·로딩이 화면 프레임을 장시간 점유하지 않도록 처리한다. 생성·해제 시 리소스 수명과 메모리 사용을 관리한다.
5. 인스턴싱은 모델·머티리얼이 공유 가능한 경우에 적용하고, 개별 오브젝트 상태는 인스턴스 데이터로 관리한다.
6. **목표 FPS, 청크 크기, 활성 반경, 렌더링 거리, LOD 수치**는 아직 정해지지 않았다. 임의로 확정하지 않는다.

## 6. 미정 / 별도 결정 필요

- 청크 크기, 마을 배치 위치. (최대 폭/해안선 사이 거리 기준은 위와 같이 확정)
- 섬 지형 높이/고도·지물 배치 및 구체적인 생성 알고리즘.
- 상품 가격/재고/수요·공급 공식과 NPC별 호감도 조정치.
- 기술 기반: 최초 기획서에는 **C++ + OpenGL**이 명시돼 있다. 다른 렌더링 API로 변경한다는 확정 지시는 이 작업 명세에 없다.

**작업 원칙:** 확정된 설정을 유지하고, 미정 사항을 자동으로 게임 규칙으로 확정하지 말 것.
