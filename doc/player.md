# 플레이어 + 선박 시스템 작업 명세

> 이 문서는 플레이어 초반 진행, 승선/조종, 선박 성장, 적재 및 항해 중 활동의 확정 규칙을 독립적으로 전달한다.

## 1. 플레이어와 초기 진행 (확정)

- 플레이어의 지름: **약 0.4m**.
- 플레이어는 **원형 시작섬**에서 게임을 시작하며, 초기에는 자신의 배가 없다.
- 시작섬에서 자금을 벌어 **50골드로 약 8m 소형 돛단배**를 구매한다. (2026-10-24 사용자 확정)
- 선박 구매 후 항해·새 섬 탐험·무역·퀘스트·동료 영입·선박 업그레이드로 모험을 확장한다.

## 2. 선박 규모와 성장 (확정)

| 구분 | 설정 |
|---|---|
| 최소 선박 | 길이 약 **8m** 소형 돛단배 |
| 최종 선박 | 길이 약 **20m**, 다중 돛대를 가진 대형 범선(제공된 참고 이미지의 형태) |
| 초기 동료 탑승 상한 | **1명** |
| 최대 동료 탑승 상한 | **5명** |
| 업그레이드 효과 | 동료 탑승 가능 인원과 선박 아이템 창(적재 용량) 증가 |

- 현재 구현 범위는 **배 미소유 → 50골드로 8m 돛단배 구매·업그레이드** 한 단계다.
- 이 단계는 **동료 정원 1명, 선박 적재 5종류 슬롯**이다. 같은 아이템은 여러 슬롯으로 나누지 않는다.
- 일반 산호 전리품과 보스 산호 전리품은 현재 각각 **최대 20개**까지 한 슬롯에 중첩한다. 한도는 아이템별로 관리한다.
- 물고기와 크라켄 촉수도 현재 각각 **최대 20개**까지 선박 슬롯에 중첩한다. (2026-10-24 사용자 확정)
- 상위 선박 단계·가격·효과와 나머지 아이템의 중첩 한도는 별도 결정한다.

## 3. 승선, 조종, 갑판 활동 (확정)

- 플레이어가 선박에 **직접 승선**할 수 있다.
- 배 위 **타륜에 접근하여 상호작용**하면 선박을 조종할 수 있다.
- 플레이어는 배 위에서 돌아다닐 수 있으며 **갑판 위 전투**도 가능하다.
- 선박에 **별도 아이템 창**이 있다. 업그레이드하면 적재 용량이 증가한다.

## 4. 플레이어의 수입 활동 (확정)

- **낚시:** 배 위에서 낚은 물고기를 마을에서 판매한다. 현재 프로토타입은 물고기 1종, 갑판 가장자리에서 5초마다 1마리, 선박 슬롯 중첩 20개, 판매가 2골드다. 음식·물약 등 소모품을 살 정도의 **보조 수입원**이다.
- **무역:** 서로 다른 섬의 특산품을 사고팔아 돈을 벌며, 주요 수입원이다.
- **탐험:** 발견한 고가치 아이템을 마을에 팔며, 주요 수입원이다.
- NPC 호감도에 따라 구매/판매 가격이 달라지고, 지나친 고가 판매는 호감도 하락을 유발할 수 있다.

## 5. 배의 적재 아이템에 적용되는 해상 위협 피해 (확정)

| 위협 | 조건 | 선박 아이템 창 손실 |
|---|---|---|
| 해적 | 승선한 해적에게 플레이어가 패배하거나, 해적선 약탈 후 40초 내 내 배로 복귀 실패 | 무작위 물건 **3개** 소실 |
| 크라켄 | 촉수 4개를 제때 절단하지 못하고 배가 파괴됨 | 무작위 물건 **2개** 소실 |
| 토네이도 | 토네이도에 휘말린 뒤 A/D 연타 탈출 실패 | 무작위 물건 **4개** 소실 |

- 2026-10-24 사용자 확정: 종류 전체를 지우지 않고, **적재품 전체의 개별 물건을 균등 추첨하여 하나씩 차감**한다. 차감 후 남은 수량에서 다시 추첨하며 같은 종류가 여러 번 뽑힐 수 있다.
- 예: 3종의 수량이 5·11·2라면 총 18개 중 4개를 무작위로 잃는다. 요청 수보다 적게 보유하면 남은 물건만 잃는다. 플레이어 가방은 손실 대상에서 제외한다.

## 6. 관련 해상 조우 규칙 (확정)

- **해적:** 플레이어 반경 **150m** 이내에 약 **2척**을 소환해 두며, 플레이어가 해적선 반경 **50m** 이내로 들어가면 추격한다.
- 해적선 접촉 피해는 없다. 선박마다 빨간 두건·칼을 든 해적 **2명**이 내 갑판에 승선한다. 각 해적의 체력은 **30**, 공격은 **10/2초**다.
- 해당 해적선의 해적을 모두 잡으면 선박 위에 **40초 카운트다운**이 시작되고 해적선 승선·약탈이 가능하다. 상자 보상은 선박당 **골드 10~20 + 크라켄 촉수 0~1개** 무작위다. 시간 안에 내 배로 복귀해야 한다.
- **크라켄:** **30초마다 1%** 발생 판정. 바다에서 **촉수 4개**가 올라와 배를 공격한다. 배가 파괴되기 전에 촉수를 잘라내면 **촉수 아이템 1개**를 획득한다. 중첩 20개이며 판매가는 미정이므로 판매 대상에서 제외한다.
- **토네이도:** **20초마다 1%** 발생 판정. 하늘이 어두워지고 비·천둥·번개가 발생하며 **배 크기 정도의 토네이도 2~3개**가 등장한다. 휘말리면 **5초 안에 A/D를 번갈아 12회** 입력하여 탈출할 기회를 준다.

### 사용자 승인 프로토타입 전투 수치 (2026-10-24)

- 선박 체력 100, 크라켄 촉수 각 체력 30·공격 5/2초.
- 기존 해적선 체력 소진·접촉 공격 방식은 승선한 해적 처치와 40초 약탈·복귀 방식으로 교체한다. 상세 규칙은 [PIRATE_BOARDING_REPORT.md](PIRATE_BOARDING_REPORT.md)를 따른다.
- 이번 구현의 세부 조작·임시 수명 및 확인 절차는 [PLAYER_IMPLEMENTATION_REPORT.md](PLAYER_IMPLEMENTATION_REPORT.md)에 기록한다.

## 7. FPS / 렌더링 성능 준수사항 (모든 작업 공통)

1. 반복 사용되는 동일 모델은 **GPU 인스턴싱**을 검토하고 메시 데이터를 재사용하여 Draw Call과 중복 리소스를 줄인다.
2. 플레이어 주변 활성 청크에서 필요한 선박/캐릭터/이펙트만 렌더한다. **멀어진 청크는 렌더링하지 않는다.**
3. 플레이어와 멀리 떨어진 선박·NPC·전투 객체를 전부 매 프레임 정밀 시뮬레이션하지 않는다. 시뮬레이션 갱신 범위와 렌더링 범위를 분리한다.
4. 승선, 타륜 조작, 갑판 이동, 선박 업그레이드에서도 불필요한 모델 복제와 리소스 생성·해제를 피한다.
5. 아직 **목표 FPS, 청크 크기/활성 반경, 선박별 렌더링 거리, 개체 업데이트 주기**는 정하지 않았다.

## 8. 미정 / 별도 결정 필요

- 이동/항해 조작 키, 속도·회전·충돌 방식 및 카메라.
- 8m 이후 배 업그레이드 단계/가격/세부 스탯, 추가 아이템의 중첩 한도, 갑판 전투 상세 규칙.
- 해상 조우의 중복 발생 방지·지속 시간·재생성 조건의 최종 밸런스. 개별 수량 손실 및 토네이도 입력 조건은 위 사용자 확정 규칙을 따른다.
- 최초 기획서는 C++ + OpenGL 기반이다. 별도 확정 없이는 API 변경을 전제하지 않는다.

**작업 원칙:** 위의 확정값을 변경하지 말고, 미정 세부사항은 사용자 확인 후 결정할 것.
