# 8종 섬 테스트 맵

작성일: 2026-10-25

## 조작

| 입력 | 동작 |
|---|---|
| T | 일반 월드 ↔ 섬 테스트 맵 왕복 |
| Y | 테스트 맵 전체 보기 ↔ 플레이어 상세 보기 |
| F1~F8 | 해당 종류 섬의 항구로 즉시 이동 |
| WASD/E/클릭 | 상세 보기에서 기존 이동·승하선·타륜·전투 사용 |
| 휠 | 상세 보기 확대/축소. 전체 보기는 창 크기에 자동 맞춤 |

T와 Y는 열린 시설/적재 메뉴를 닫는다. T는 포획·해적선 승선 중에도 왕복할 수 있다. 테스트 맵에서는 F1~F8 섬 선택을 우선하므로 기존 Debug F6~F8 해상 강제 조우는 일반 월드에서 사용한다. 상세 보기의 O/P는 기존 토네이도·크라켄 소환으로 동작한다.

첫 진입은 전체 보기다. 전투·약탈/탈출 타이머·낚시 진행은 일시 정지하며, 섬 청크와 모델 로딩은 계속한다. 전체 보기에서 몬스터 이름·체력바와 큰 상태 패널을 감춰 섬 형태를 확인하기 쉽게 했다. Y 또는 F키로 상세 보기에 들어가면 다시 진행한다.

## 2행 × 4열 고정 배치

| 행 | 1열 | 2열 | 3열 | 4열 |
|---|---|---|---|---|
| 1행 | F1 원형 | F2 초승달형 | F3 U자형 | F4 아령형 |
| 2행 | F5 불규칙형 | F6 물방울형 | F7 분열형 | F8 암초군형 |

- 모든 종류가 하나씩 존재한다. 확률로 종류를 고르지 않는다.
- 섬 최대 폭은 각 40m, 중심 간격은 96m다. 각 섬은 3×3개 청크 타일에 배치하며, 땅/부두가 자기 타일 밖으로 나가지 않는지 초기 구성 시 검사한다.
- 일반 월드의 40~80m/해안선 간 최소 300m/무한 생성 규칙은 그대로 유지한다. 테스트 맵만 가까운 간격을 사용한다.
- 항구 마을·상점·조선소·부두와 섬별 일반 4종/에픽 1종은 같은 IslandLayout과 MonsterSystem을 사용한다. 드랍 비활성 정책도 동일하다.
- 테스트 맵에는 해당 8개 타일과 주변 한 청크의 바다만 로딩 대상으로 둔다. 섬 타일을 빈 바다보다 먼저 준비하고, 나머지 청크는 기존처럼 업데이트당 1개씩 생성한다. 첫 전체 보기에서는 섬이 순차적으로 표시될 수 있다.
- 순간 이동 시 발밑 주변 3×3 청크는 즉시 준비하고 생성 대기열에서 중복을 제거한다. 상세 보기의 평상시 스트리밍/언로드는 기존 경계를 따른다.

## 일반 월드 보호와 왕복 상태

- 월드의 청크·섬·생성 대기열을 두 보관 영역으로 나눠 전환한다. 비활성 월드의 Actor 루트는 렌더링/갱신에서 제외한다.
- 몬스터와 해상 전투 시스템도 월드별로 보관해 비활성 월드의 처치 상태·체력·확률 시계·해적 약탈 타이머·토네이도 탈출 시간을 정지한다.
- 플레이어/선박 위치, 카메라·확대, 도보/갑판/타륜/해적선 상태, 체력·경험치·레벨·무기·강화·골드·가방·적재·선박 소유권을 월드별로 저장하고 복원한다. 해적선 위였다면 그 선박 Actor에 다시 연결한다.
- 테스트 맵의 진행은 일반 월드에 반영하지 않는다. 처음 진입할 때 별도 초기 상태와 확인용 예산 50골드로 8m 돛단배를 자동 구매한다. 따라서 테스트 모드의 초기 잔액은 0이며, 일반 월드의 골드는 사용하지 않는다.
- F키 이동은 테스트 위치/배를 해당 항구에 놓고 플레이어 체력을 회복하며 테스트 해상 조우를 초기화한다. 테스트 경험치·장비·아이템은 유지한다.
- 열린 메뉴, 진행 중 낚시, 공격 궤적·피해 숫자는 전환 시 종료한다. HDR/격자/HUD 같은 표시 설정은 공통이다.
- 테스트 방문은 일반 월드 방문 저장 파일을 읽거나 쓰지 않는다. 테스트의 같은 섬 좌표가 일반 저장 기록과 섞이지 않는다.
- 보관은 현재 실행의 메모리 상태이며 새 영구 저장 시스템은 아니다. 프로그램 재시작 시 기존 세션 초기화 정책을 따른다.

## 구현과 분석

- IslandTestMap: 8종 고정 descriptor, 2×4 배치 및 청크 타일 매핑.
- WorldTestMap: 두 월드의 청크/섬/대기열 전환과 순간 이동 주변 준비.
- PrototypeTestMap: 플레이어 진행/경제 스냅샷, 활성 전투 시스템 교체, T/Y/F키와 배치도 UI.
- PlayerProgressState: 플레이어 진행 상태 캡처/복원과 전환 시 전투 효과 정리.
- MarineSystem/MonsterSystem의 비활성 루트를 중지하고 기존 공용 메시·GPU 인스턴싱을 재사용한다. 두 월드의 상주 자산을 보관하므로 메모리는 활성 월드 하나만 유지할 때보다 늘 수 있다.

로그:

- test_map_layout / test_island_created: 2×4 구성·간격, 종류 번호·행/열·섬 폭.
- world_map_switch: 활성 월드 종류.
- test_map_travel: 일반/테스트 왕복과 복원된 골드·플레이어 체력·청크/로컬 좌표·갑판 상태.
- test_island_teleport: F키 대상 번호.
- world_window/chunk_generated/world_stream: mode=adventure/test 구분.
- 테스트 지형 배치 이름은 test_map_chunk_X_Z로 구분한다. 몬스터/캐시/FPS/CPU/인스턴스 로그는 기존 기록을 함께 사용한다.

## 확인 범위와 수동 확인

빌드·실행·화면 결과 확인은 수행하지 않았다. 프로젝트 XML·경로·소스/필터 일치·PCH, 8종/2×4/타일당 9청크 매핑, 진행 상태 필드의 캡처/복원 대응, 테스트 방문 저장 제외, 즉시 준비 후 대기열 재구성, 입력 우선순위와 코드 형식을 정적으로 점검했다.

1. 일반 월드의 위치·골드·체력·아이템 수를 기록하고 T로 들어간다. 2×4 전체 배치와 종류 안내를 확인한다.
2. F1~F8로 모든 섬의 항구/몬스터/에픽을 확인한다. 배가 해당 부두에 있고 즉시 승선·항해가 가능한지 확인한다.
3. 테스트에서 전투·약탈·골드·적재를 변경한 뒤 T로 돌아온다. 일반 월드의 위치/방향/체력/진행/아이템/선박 상태가 복원되는지 확인한다.
4. 일반 월드 해적선 약탈·크라켄·토네이도 중 T 왕복하여 일반 월드 타이머와 갑판 부모가 보존되는지 확인한다.
5. 테스트 상세 전투 중 Y 전체 보기에서 체력/타이머가 멈추고 Y 복귀 시 재개되는지 확인한다.
6. T를 반복해도 같은 월드 루트가 누적 생성되지 않는지, 비활성 월드가 렌더/AI 갱신에 포함되지 않는지 로그와 Actor/배치 수로 확인한다.
