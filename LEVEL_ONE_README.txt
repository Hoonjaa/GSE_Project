레벨 1: 새싹 탐험가의 섬

목표
----
일반 적 처치 → 경험치/장비 획득 → 무기 강화 → 보스 처치를 익히는 파밍 튜토리얼.
기존 시작 섬 반경 9에서 약 45로 확대했다.
가로·세로 약 5배이며 면적 기준으로는 약 25배다.
32단위 청크 크기는 유지하며 하나의 시작 섬이 여러 청크에 걸쳐 이어진다.
주변 대양의 다른 섬은 기존 생성 규칙을 유지한다.

조작
----
WASD: 이동
좌클릭: 커서 방향 120도 부채꼴 근접 공격
Space: 달리기
F: 강화석을 소비해 현재 무기 강화
E: 승선/하선 (배는 시작 지점 동쪽의 해안 부두에 정박)
R: 항구 복귀 및 회복 (프로토타입 편의 기능)
V: 성장 정보/후처리 설정 안내 전환
H: HUD 숨김
기존 P, 1, 2, 3, [, ], 0 후처리 단축키와 휠 줌도 유지한다.
좌클릭은 한 번 누를 때 한 번 공격하며 누르고 있어도 자동 연사하지 않는다.
보이는 주요 UI 패널 위의 클릭은 공격으로 처리하지 않는다.
항해 중에는 육상 근접 공격을 사용할 수 없다.

성장과 장비
-----------
시작: 캐릭터 레벨 1, 체력 100, 공격력 10.
레벨 상승당 최대 체력 +18, 기본 공격력 +3, 획득 반경 +0.08.
필요 경험치: 40 + (현재 레벨 - 1) * 25.
일반 적 경험치 18, 보스 경험치 160.
레벨 업 시 체력 전부 회복. 현재 성장 상한은 레벨 20.
5초 동안 피해를 받지 않으면 초당 2 회복, 항구 안전 지점에서는 초당 12 회복.
피격 후 0.65초 무적으로 다수 적의 동시 피해를 제한한다.
사망 시 항구 복귀, 체력 회복, 경험치/장비/강화석 유지.

공격력 = 10 + (레벨 - 1) * 3 + 무기 기본 보너스 + 강화 단계 * 2.
공격 쿨다운 0.42초, 기본 사거리 2.7, 공격각 120도.
타격 이펙트, 피해 숫자와 적 체력바를 표시한다.
벽/바위 너머의 적은 공격 경로 검사로 피해를 받지 않는다.

일반 적은 매번 강화석 1개를 떨어뜨린다.
첫 처치는 무기 드랍 보장, 이후 일반 적은 30% 확률로 무기 드랍.
일반 무기 공격력 보너스 4~11, 보스 무기는 +18.
훈련용 검 → 선원 단검/해적 커틀러스 → 산호 대검 형태의 초기 장비 구분이다.
강한 무기는 자동 장착하며, 동급 이하 무기는 강화석 1개로 전환한다.
강화 단계는 새 무기로 교체해도 유지한다.
강화 비용은 현재 강화 단계 + 1개의 강화석, 성공률 100%, 최대 +10.
수동 인벤토리/장비 선택과 별도 무기 모델은 후속 작업이다.

자석 습득
---------
기본 반경 3.8 안에 들어온 아이템이 플레이어를 향해 가속한다.
바위가 있으면 이동 가능한 경로를 따라 돌아온다.
0.65 이내에서 자동 습득하며, 항해 중에는 습득하지 않는다.
일반 드랍은 120초 후 정리, 보스 보상은 이번 실행 중 유지한다.
개별 적 재생성 25초, 플레이어가 해당 생성 지점에서 12 이상 떨어졌을 때만 재생성한다.
동시에 유지하는 적/드랍/피해 숫자 수는 제한한다.

맵 생성과 이동 안전
-------------------
시작 섬은 실행마다 새 시드를 사용하고, 같은 실행 중에는 지형과 상태를 유지한다.
시드는 하단 상태 표시에서 확인할 수 있다.
해안 형태, 바위, 적 배치가 랜덤이며 시작 항구와 보스 광장은 고정 앵커다.
중앙의 넓은 통로, 항구 출발 공간, 북쪽 보스 광장을 먼저 비워 둔다.
이후 장애물을 배치하고 출발점부터 4방향 BFS로 연결성을 검사한다.
단절이 발생하면 랜덤 장애물을 제거해 복구하고, 남은 비연결 지점은 배치 후보에서 제외한다.
적은 시작점에서 도달 가능한 셀 중심에만 배치한다.
캐릭터 충돌은 0.28 여유 폭을 고려하며 대각선으로 장애물 모서리를 통과하지 못한다.
적과 자석 아이템은 플레이어까지의 거리장을 이용해 장애물을 우회한다.
큰 섬과 중복되지 않도록 인접 청크의 기존 작은 섬 생성은 억제한다.

보스
----
북쪽 광장의 '산호갑각 대장', 체력 360.
접근하면 전투 시작. 보스 공격은 붉은 원으로 0.95초 전에 예고한다.
공격 범위 반경 3.6, 피해 30. 체력이 절반 이하가 되면 공격 간격이 짧아진다.
처치 보상: 경험치 160, 강화석 8개, 공격력 +18 무기.
처치 후에는 레벨 1 완료 상태로 남으며 이번 실행 중 보스는 재생성되지 않는다.
보스를 처치한 후에도 일반 적 파밍을 계속할 수 있다.
레벨 3과 무기 강화는 권장 준비 상태이며 보스 입장 제한 조건은 아니다.
적이 추적 범위를 벗어나거나 플레이어가 항구/배로 피하면 살아 있는 적의 위치와 체력이 초기화된다.

사용자 확인 순서
----------------
1. 항구에서 이동해 이전보다 훨씬 큰 섬과 한국어 성장 HUD를 확인한다.
2. 지도에서 금색 시작점, 흰색 플레이어, 붉은 보스 지점을 확인한다.
3. 항구 밖의 일반 게를 클릭 방향에 맞춰 공격한다.
4. 적 체력 감소/피해 숫자/공격 간격을 확인한다.
5. 드랍 가까이 접근해 자석 이동, 강화석 증가와 무기 자동 장착을 확인한다.
6. F로 강화하고 공격력 증가와 강화석 차감을 확인한다.
7. 경험치로 레벨 업하여 최대 체력/공격력 증가를 확인한다.
8. 바위를 사이에 두고 이동/공격/적 추적/아이템 우회를 확인한다.
9. 북쪽 보스의 붉은 원을 피하면서 싸우고 완료/보상을 확인한다.
10. 사망, R 복귀, 일반 적 재생성, 출항/귀환 시 상태 유지를 확인한다.

현재 범위
---------
구현 코드와 프로젝트 연결, 코드 포맷을 정리했다.
빌드, 실제 전투 플레이, 대량 시드 생성 및 성능 확인은 수행하지 않았다.
맵/경험치/장비/드랍/보스 처치 상태는 실행 중 메모리에만 보관한다.
프로그램 재실행 시 새 맵으로 시작하며 저장/불러오기는 후속 작업이다.
지형은 초기 셀 기반 메시이며 최종 아트, 정교한 적 간 충돌, 전투 애니메이션과 밸런스는 후속 작업이다.

파일
----
LevelOneTerrain: 랜덤 시작 섬, 연결성 검사, 충돌, 경로장, 해도.
LevelOne: 전투, 성장, 드랍, 자석 이동, 보스, 한국어 전투 HUD.
World: 큰 시작 섬과 기존 청크/해상 월드 연결.
Prototype: 마우스 조준, 공격 입력, 승하선, 사망 복귀와 표시 연결.
Renderer: 화면 좌표와 지면 좌표 변환.
